# Queries: аргументы и состояния загрузки

<div className="learning-note"><strong>После урока ты сможешь</strong><p>Различать загрузку без данных и обновление уже существующего результата.</p></div>

Перед началом: пройди [предыдущий урок](/redux/lessons/rtk-query-setup/).

## Запрос описывает данные

Query endpoint используется для чтения. Вызов hook создаёт подписку на данные конкретного endpoint и аргумента. Не помещай рядом `useEffect`, который дублирует тот же запрос через fetch.

```tsx
import { api } from './api';
function PostCard({ id }: { id: number }) {
  const { data, currentData, isLoading, isFetching, isError, refetch } =
    api.useGetPostQuery(id);
  if (isLoading) return <p>Первая загрузка…</p>;
  if (isError && !currentData) return <p>Ошибка загрузки</p>;
  return <section aria-busy={isFetching}>
    <h3>{currentData?.title ?? 'Загружаем выбранную запись…'}</h3>
    {isFetching && <p>Обновляем данные…</p>}
    <button onClick={() => refetch()} disabled={isFetching}>Обновить</button>
  </section>;
}
```

Это компонент для API из урока 12. `data` оставлен в деструктуризации для сравнения с `currentData`: в реальном коде неиспользуемую переменную убери.

## Два разных флага

`isLoading` обозначает первую загрузку hook, когда данных ещё нет. `isFetching` показывает выполнение запроса, в том числе повторного. При refetch уже загруженные данные можно оставить на экране и показать небольшой индикатор вместо полноэкранного спиннера.

`data` — последний доступный результат hook; при смене аргумента это могут быть данные прежнего аргумента. `currentData` относится к текущему аргументу. Для карточки выбранной записи часто безопаснее показывать `currentData`, чтобы не подписать прежнее название новым id.

## Аргумент — часть идентичности

`useGetPostQuery(1)` и `useGetPostQuery(2)` — разные записи кэша. Изменение id переключает подписку. Если нужен составной аргумент, передай один объект, например `{ id, locale }`, и опиши его тип в endpoint.

Не включай в аргумент случайное число или текущую дату ради перерендера: это создаёт новые ключи и лишние запросы. Для явного обновления есть `refetch`.

## Эксперимент

Дождись загрузки A и нажми Refetch. Заметь, что название остаётся на экране, `isFetching` меняется, а счётчик запросов увеличивается. Включи B с id 2: его загрузка относится к другой записи.

## Что запомнить

Отображение загрузки зависит от того, есть ли данные. Ключ запроса определяется endpoint и аргументом, а не местом компонента в дереве.
