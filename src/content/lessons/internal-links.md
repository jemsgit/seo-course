Читатель может открыть урок о поисковых запросах прямо из выдачи. Если на странице есть ссылка на модуль, он увидит, что уже пропустил и что может прочитать дальше. Ссылка внутри урока решает более узкую задачу. Например, при сомнении, объединять ли два запроса, можно сразу перейти к [сравнению выдачи](/lessons/search-intent/).

## Проверьте путь от главной

На нашем сайте [главная](/#program) ведёт к [странице модуля](/modules/content/), где собраны опубликованные уроки по порядку. Урок ссылается обратно на модуль через хлебные крошки. Внизу есть переходы к соседним урокам. Через эту навигацию до статьи легко добраться, даже если читатель забыл её название.

Проверьте новые URL после сборки. Если до статьи можно добраться только по прямому адресу, добавьте её в нужный раздел или свяжите с материалом, который уже есть на сайте. Для проверки курса используем команды `npm run build` и `npm run check`. Сборка генерирует навигацию из опубликованных уроков, а проверка находит ссылки и якоря, ведущие на отсутствующие страницы и разделы.

## Поставьте ссылку там, где она нужна

Внутри статьи полезно ссылаться на следующий шаг. Например, из инструкции по сбору запросов можно вести к [уроку о заголовке и описании](/lessons/title-h1-description/), когда читатель уже выбрал тему. По тексту ссылки должно быть понятно, куда она ведёт. В Markdown это обычная ссылка, которая после сборки становится элементом `<a href>`:

```md
[Как написать заголовок и описание](/lessons/title-h1-description/)
```

Если навигация сделана через кнопки с обработчиками JavaScript, проверьте исходный HTML. Для переходов между страницами используйте ссылки с адресом в `href`. Google документирует этот формат как доступный для обхода.

## Практика

1. Откройте урок с главной, затем представьте, что нашли его через поиск. Проверьте, куда ведут хлебные крошки и как перейти дальше.
2. Выберите место в статье, где у читателя может возникнуть конкретный вопрос. Добавьте одну ссылку на материал, который отвечает на него.
3. После сборки откройте ссылки и проверьте их текст. Если ссылка ведёт на заголовок внутри статьи, убедитесь, что нужный раздел открывается.
