В магазине обуви есть фильтры по цвету, размеру, цене и бренду. Из нескольких десятков значений получается множество комбинаций URL. «Чёрные кроссовки» могут быть полезной подборкой из поиска. Сортировка той же подборки по цене нужна человеку уже внутри магазина. Если каталог открывает для обхода все варианты, роботы могут тратить запросы на повторяющиеся списки, пока новые карточки ждут обхода.

## Выберите подборки для поиска

Начните с категорий и нескольких фильтров, которые отвечают на [отдельные задачи покупателей](/lessons/search-intent/). Проверьте спрос и ассортимент. Если человек ищет чёрные кроссовки и такая подборка регулярно заполнена, дайте ей постоянный адрес, понятный заголовок и ссылку из категории. Если подборка нужна лишь для настройки текущего просмотра, решите отдельно, должны ли поисковики её обходить.

| URL в учебном магазине | Что сделать |
| --- | --- |
| `/sneakers/` | Основная категория. Дать на неё ссылку из навигации |
| `/sneakers/black/` | Подборка под отдельный запрос. Если ассортимент стабилен, открыть для обхода и добавить ссылку из категории |
| `/sneakers/?sort=price` | Сортировка. Оставить сортировку в интерфейсе. Если робот тратит на эти URL много запросов, проверить вариант ограничения обхода |
| `/sneakers/?utm_source=newsletter` | Метка перехода. Если список тот же, указать основной URL без метки |
| `/sneakers/?page=999` | Несуществующая страница пагинации. Если последняя страница имеет номер 12, вернуть `404` |

Если каталог публикует адреса фасетных страниц, приведите порядок параметров к одному варианту. Например, ссылки на одну и ту же комбинацию должны использовать одинаковый порядок `color` и `size`. Для доступных обходу комбинаций без результатов Google рекомендует вернуть `404` по самому адресу. На странице ошибки можно оставить фильтры и предложить снять часть условий.

## Управляйте обходом и индексированием отдельно

Если нужно уменьшить обход служебных комбинаций, рассмотрите правила `robots.txt` для соответствующих URL. Сначала проверьте, что правила сохраняют доступ к категориям, нужным подборкам и пагинации. Для URL, который доступен пользователю и должен уйти из поиска, применяйте [`noindex` с доступом для обхода](/lessons/robots-txt/). Роботу нужно получить ответ, чтобы прочитать это указание.

Используйте [`canonical`](/lessons/canonical-urls/) для дублей или очень похожих вариантов. Подборка с другим набором товаров может отвечать на самостоятельный запрос. Сводить её к общей категории только потому, что в адресе есть фильтр, рискованно. В Яндексе `Clean-param` подходит для параметров, которые не меняют содержимое, например для проверенной метки рассылки. Параметры цвета, размера и номера страницы могут менять сам список.

## Дайте роботу путь до каждой карточки

Робот должен иметь возможность открыть категорию, перейти на следующую страницу и найти ссылку на товар. Для пагинации дайте каждой странице собственный URL, например `/sneakers/?page=2`, и поставьте обычные ссылки `<a href>` между страницами. Если на второй странице другой набор товаров, укажите её собственный канонический адрес. Страница 1 и её вариант `?page=1` могут быть дублями. Для них выберите один основной URL.

Если в интерфейсе есть кнопка «Показать ещё», сохраните доступные по прямому адресу страницы списка, связанные ссылками. Google обычно обнаруживает URL по `href` и не нажимает кнопки ради загрузки карточек. [Sitemap](/lessons/sitemap-xml/) с основными URL товаров помогает их обнаружить. Ссылки из каталога по-прежнему нужны, чтобы пройти тот же маршрут прямо на сайте.

## Практика

1. Возьмите одну категорию и выпишите пять URL: саму категорию, полезную подборку, сортировку, страницу 2 и карточку из этой страницы. Для каждого запишите ожидаемый HTTP-статус, возможность обхода и канонический адрес.
2. Откройте страницу 2 напрямую. В исходном HTML найдите ссылку на карточку, затем проверьте, есть ли на странице 1 ссылка на страницу 2. Повторите для одной страницы ближе к концу списка.
3. Проверьте одно правило, которое ограничивает обход фильтров. Проверьте, совпадёт ли с правилом служебный URL и останутся ли доступными подборка и страница 2. На опубликованном сайте посмотрите, что сообщают по этим адресам Google Search Console и Яндекс Вебмастер.
