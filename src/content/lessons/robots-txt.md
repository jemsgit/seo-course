Если `/robots.txt` возвращает `404`, отсутствие файла само по себе не мешает обходу. Робот может найти статью по ссылке, запросить её и обработать для поиска. Важно проверить код именно у файла. Ответ `404` от самой статьи означает, что по этому адресу сервер сообщает об отсутствии страницы. Сбой сервера на `/robots.txt` тоже отдельный случай: Google обрабатывает ответы `5xx` иначе, чем `404`.

## Что меняется, когда файл появляется

Файл размещают по адресу `/robots.txt` в корне сайта. На курсе он разрешает обход и указывает адрес [карты сайта](/lessons/sitemap-xml/). Если у сайта появился общедоступный служебный раздел и задача состоит в том, чтобы поисковые роботы не запрашивали его страницы, можно добавить правило для пути. Пример для вымышленного сайта:

```text
User-agent: *
Disallow: /internal-search/
Sitemap: https://seo.example.com/sitemap.xml
```

Правило относится к адресам, путь которых начинается с `/internal-search/`. Если такой URL уже известен по ссылкам, он всё ещё может появиться в поиске. Пользователи тоже смогут открыть его, пока сервер отдаёт страницу всем.

## Когда подходит noindex

Иногда страницу надо оставить доступной по прямому адресу, но исключить из поиска. Например, открытое демо предназначено для читателей конкретного урока. Оставьте доступ для робота и добавьте в `<head>`:

```html
<meta name="robots" content="noindex">
```

То же указание можно передать HTTP-заголовком `X-Robots-Tag: noindex`, например для PDF. Если одновременно закрыть URL через `Disallow`, робот может не получить страницу и не увидеть указание. Для уже известной страницы изменение статуса требует повторной обработки.

## Что выбрать для своей страницы

| Страница | Задача | Настройка |
| --- | --- | --- |
| Опубликованный урок | Дать поисковику возможность обнаружить и прочитать текст | Обычная внутренняя ссылка, ответ `200`, доступ для обхода и индексирования |
| Общедоступное служебное демо | Открывать его по прямой ссылке и исключить из поиска | Доступ для обхода и `noindex` |
| Закрытый предпросмотр | Пускать только участников проекта | Авторизация или ограничение доступа на уровне хостинга |

Для предпросмотра проверяйте доступ без авторизации. На курсе черновики дополнительно исключены из публичной сборки.

## Практика

1. Проверьте ответы для `/robots.txt` и урока на опубликованном сайте. Подставьте свой домен в команду `curl -sS -D - https://seo.example.com/robots.txt`. Если файл есть, найдите группу правил для нужного робота и проверьте путь урока.
2. Возьмите тестовую страницу, которую можно читать по ссылке. Проверьте исходный HTML и HTTP-заголовки на `noindex`. Если URL должен быть исключён из поиска, убедитесь, что робот может получить этот ответ.
3. Откройте закрытый предпросмотр без входа. Убедитесь, что видите экран входа или отказ в доступе. Открытая страница с `noindex` доступна любому посетителю, у которого есть адрес.
