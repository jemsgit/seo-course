# Список задач на React и RTK Query

Требуется Node.js 22.23.4 или новее.

```sh
npm install
npm run dev
```

Открой адрес из терминала. На главной странице работает готовая версия. Начни с
`/starter.html` или запусти `npm run dev:starter`, чтобы сразу открыть заготовку.
Учебный API хранит данные в памяти и сбрасывается при перезагрузке.

Шаги работы описаны в уроке «Сквозной проект». В готовой версии `tasks-api.ts`
создаёт API и store, `TaskBoard.tsx` содержит фильтр, список и форму,
а `TaskBoardDemo.tsx` подключает Provider и учебный транспорт из `demo-api.ts`.

Для интеграционной проверки открой `/test.html` на том же сервере. Тест
монтирует настоящий React-интерфейс с Provider и RTK Query. Он меняет фильтр,
проверяет URL и историю, отправляет неуспешное сохранение и повторяет его
с успешным ответом. Результат появится прямо на странице.
