# SEO Практика

Статический курс по SEO для веб-разработчиков. Программа и правила подготовки материалов находятся в [плане курса](COURSE_PLAN.md).

## Запуск

Нужен Node.js 22.23.4 или новее.

```sh
npm ci
npm run dev
```

Чтобы проверить готовую сборку локально:

```sh
npm run build
npm run check
npm run preview
```

## Публикация

Подставьте HTTPS-домен сайта в обе команды:

```sh
SITE_URL=https://seo.example.com npm run build
SITE_URL=https://seo.example.com npm run check
```

Выложите содержимое `dist/` на статический хостинг. Настройте раздачу `index.html` из каталогов и страницу `404.html` с HTTP-статусом 404. Канонические адреса и sitemap используют `SITE_URL`. Сборки без этого параметра получают `noindex` и пустой sitemap.

## Уроки

Файлы уроков лежат в `src/content/lessons/`. Схема проверяет метаданные при сборке. Для нового урока выберите постоянный `slug` и свободную позицию внутри модуля. Поставьте `draft: true`, пока урок в работе. Перед публикацией проверьте источники и пройдите редактуру с навыком `humanizer:humanizer`.
